Клонируй свой форк
git clone https://github.com/твой-username/название-репозитория.git

Создай новую ветку
git checkout -b dev1

После внесения изменений добавь их в staging area:
git add .

Создай коммит с описанием изменений:
git commit -m "Описание изменений"

Отправь свои изменения в свой форк на GitHub:
git push origin имя-твоей-ветки
