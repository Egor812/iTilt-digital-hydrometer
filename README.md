
# ОПИСАНИЕ

Основано на проекте iTilt. Устройство предназначено для беспроводного непрерывного измерения SG( удельного веса ) во время ферментации сусла. Полученные данные отправляются на сервер.
Состоит из микроконтроллера Seeedstudio ESP32C3, гироскопа MPU6050, датчика температуры DS18B20, аккумулятора 18650 и PET преформы. При ферментации количество сахара уменьшается и плотность сусла снижается. Сначала устройство будет плавать под большим углом. Но по мере снижения уровня сахара стремиться к вертикальному положению. Угол наклона пересчитывается в SG и передается на сервер.

# ПРЕИМУЩЕСТВА
Работа при постоянно и периодически доступной сети Wifi. Если бродильные емкости стоят в месте без постоянного доступа в интернет, то данные будут сохранятся в памяти и выгружаться на сервер при появлении сети.

# Настройка
## Настройка WiFi
Ввести SSID и пароль вашей wifi сети.
### Проблемы Windows
- Через Windows портал настройки может не работать из-за firewall.
- Если при нажатии "Настройка Wifi" теряется связь с точкой доступа и вы подключаетесь к вашему обычному wifi - уберите галку "Подключаться автоматически" на вашей обычной сети и поставте на iTilt_x
- Через Windows портал настройки - "Настройка Wifi" может не загружаться полностью
- Иногда всё так плохо, что приходится перезагружать Windows
- 192.168.4.1/0wifi - настройки wifi без сканирования сетей.


##Настройки устройства
Сервер:
- COG сервер : url моего сервера
- логин и пароль : от учетной записи на COG
Коэффициенты:
- коэффициенты Tilt^3, Tilt^2, Tilt^1, свободный член: получаем в меню "Калибровка плотности"
- коэффициент вольтметра : если предустановленный не устраивает, то вычисляется по формуле: k = Вольт на A0 / Вольт на аккумуляторе. В идеальном мире k = R2/(R1+R2) = 10k / (10k+4.7k) = 0.68
Отправка данных. Время через которое устройство проснется. Считает данные. Отправит/сохранит. Заснет.
- интервал отправки данных (с) : минимальное значение 10с. При значении менее 60с устройство не засыпает и работает постоянно. 
- интервал сохранения данных в автономном режиме (с) : если данные не удается отправить в течении этого времени, то устройство переходит в автономный режим. Теперь будет собирать и пытаться отправить данные через этот интервал.

- Начальная плотность - [не актуально] необязательный параметр. Влияет только на данные в портале настройки. Это значение задается на сервере для каждой емкости.
- смещение гироскопа - [не актуально]
- iTilt ID: числовое значение 0..65535. Важно указывать уникальный id для каждого активного устройства. iTilt ID привязывается к ID емкости на сервере, и устройство будет передавать данные в эту емкость. Если емкость помещена в архив, то данные добавляться не будут.
- таймаут портала настройки - [еще не работает]
- язык: язык портала настройки
