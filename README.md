
# ОПИСАНИЕ

Основано на проекте iTilt. Устройство предназначено для беспроводного непрерывного измерения SG( удельного веса ) во время ферментации сусла. Полученные данные отправляются на сервер.
Состоит из микроконтроллера Seeedstudio ESP32C3, гироскопа MPU6050, датчика температуры DS18B20, аккумулятора 18650 и PET преформы. При ферментации количество сахара уменьшается и плотность сусла снижается. Сначала устройство будет плавать под большим углом. Но по мере снижения уровня сахара стремиться к вертикальному положению. Угол наклона пересчитывается в SG и передается на сервер.

# ПРЕИМУЩЕСТВА
Работа при постоянно и периодически доступной сети Wifi. Если бродильные емкости стоят в месте без постоянного доступа в интернет, то данные будут сохранятся в памяти и выгружаться на сервер при появлении сети.
